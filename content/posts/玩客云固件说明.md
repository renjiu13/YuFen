## 文件名结构

```
Armbian-unofficial_25.11.0-trunk_Onecloud_{发行版}_current_6.12.43{变体}.{格式}.xz
```

---

## 参数对照

| 参数位置    | 可选值             | 含义                   |
| :------ | :-------------- | :------------------- |
| **发行版** | `bookworm`      | Debian 12（稳定版，推荐）    |
|         | `trixie`        | Debian 13（测试版）       |
|         | `sid`           | Debian 不稳定版（最新）      |
|         | `noble`         | Ubuntu 24.04 LTS（推荐） |
|         | `oracular`      | Ubuntu 24.10         |
|         | `plucky`        | Ubuntu 25.04         |
| **变体**  | *(空)*           | 标准版（通用，~450MB）       |
|         | `_minimal`      | 最小化（无桌面，~250MB）      |
|         | `_xfce_desktop` | 带桌面（~850MB）          |
| **格式**  | `.img`          | 标准镜像（写 SD 卡/U 盘）     |
|         | `.burn.img`     | 直刷镜像（刷 eMMC）         |

---

## 快速选型

| 场景 | 选这个 |
|:---|:---|
| 刷 eMMC（直刷）| `*.burn.img.xz` |
| 写 SD 卡/U 盘 | `*.img.xz` |
| 服务器/NAS/下载机 | `*_minimal.burn.img.xz` |
| 通用基础系统 | `*.burn.img.xz`（标准版）|
| 需要图形桌面 | `*_xfce_desktop.burn.img.xz` |
